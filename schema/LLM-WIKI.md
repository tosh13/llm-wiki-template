# LLM Wiki 連携

個人用知識ベース `~/llm-wiki/` をKarpathyパターンで維持管理する。
スキーマ詳細は `~/llm-wiki/CLAUDE.md` を参照。
**Claude Codeは全プロジェクトの作業中、以下を自律的に行う。ユーザーへの確認は不要。**

## 人物情報の取り扱い（最優先・厳守）

人物（**本人を含む**）の固有情報を扱う際は `~/.claude/PERSON-PROTOCOL.md`（SessionStartで提示）の R1-R4 を厳守する：
- **R1 参照優先**：人物の属性（肩書・役割・所属・メール・関係性・経歴）を述べる前に、**正規ローカル記録を必ず読む**（人物 entity ページ `wiki/entities/<slug>.md`、組織メンバーの基礎情報は各プロジェクトの一次データ）。**グローバル設定の自己紹介欄は概要であり正本ではない**（本人の正本は entity ページ）。
- **R2 推測禁止**：人名（漢字含む）・役職を推測しない。未確認の固有名は確認まで保留。
- **R3 セッション末・もれなく追記**：関与・言及した各人物の新事実（役割変更・接触記録・評価・訂正）を該当 entity と `log.md` に**漏れなく**追記（SESSION-END 必須）。
- **R4 全情報をwikiに集約・ラベル管理**：機微情報も含め人物情報は wiki entity に記載し `sensitivity`（public/internal/confidential、人物は既定 confidential）で機密管理。別ストアに分離しない。

## Ingest（取り込み）

セッション中に蓄積すべき知識を発見したら：
1. ~/llm-wiki/CLAUDE.md を読んでスキーマを確認
2. ~/llm-wiki/index.md で既存ページを確認し、重複・更新対象を特定
3. sources/ に原資料を格納（外部ファイルは参照ポインタ）
4. wiki/ 配下の該当ページを更新 or 新規作成
5. index.md, log.md を更新
6. ユーザーに「wikiを更新しました: [[ページ名]]」と一言報告

Ingest対象：
- プロジェクト横断で有用な概念・知識・事実
- 意思決定とその理由
- 人物に関する情報（関係性、接触記録、評価）
- 法令・規制・基準に関する情報
- 比較分析・調査結果

Ingest対象外：
- プロジェクト固有の一時的な実装詳細（コードの書き方等）
- 単純なバグ修正・手順実行の記録
- gitログやコミット履歴から復元できる情報

## Query（参照）

ユーザーの質問がwikiの蓄積知識で回答できそうなとき：
1. ~/llm-wiki/index.md を読み、関連ページを特定
2. 該当ページを読んで回答に活用
3. 回答が新たな分析・整理を含む場合、wikiにページとして保存

## コンテキスト効率

毎回全ページを読む必要はない。index.md（目次）だけを読み、関連がありそうな場合のみ
個別ページを読む。関連がなければwiki操作は行わずセッションを進める。

## セッション終了時

llm-wiki の維持はセッション中の自動Ingestだけでなく、セッション終了時にも走る。ユーザーが終了を告げたら（「終わります」「セッションを終える」等）、そのセッションで扱ったwiki関連の変更を確定してから終える：

1. そのセッションで得た新事実・接触記録・訂正を、関与・言及した各 entities ページに漏れなく追記（人物は R3 に従う）
2. そのセッションの追加・更新・移動を log.md の先頭に追記
3. index.md を実体と一致させる

Claude Code のグローバル設定（`~/.claude/CLAUDE.md`）にセッション終了ルーチン（SESSION-END.md 等）を持つ場合は、その一部としてこの wiki 処理を組み込む。ルーチンを持たない場合でも、上記はこの LLM-WIKI.md の指示として終了時に実行する。

## 「会話の記録・保存」との使い分け

- プロジェクト固有の設計文書・手順書 → そのプロジェクトの docs/ に保存
- プロジェクト横断の知識・判断・人物情報 → ~/llm-wiki/ に保存
